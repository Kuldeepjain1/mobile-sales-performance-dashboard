# 📊 Mobile Sales Performance Dashboard | Power BI

## 📌 Project Overview
This project presents an interactive Power BI dashboard designed to analyze
mobile sales performance across brands, models, cities, payment methods, and time.

The dashboard helps stakeholders track key KPIs, identify trends, and understand
customer purchasing behavior for data-driven decision-making.

---

## 🎯 Key KPIs
- Total Sales
- Total Quantity Sold
- Total Transactions
- Average Sales Value

---

## 📈 Dashboard Features
- Brand and mobile model performance analysis
- City-level geographical sales insights
- Monthly and weekday sales trend analysis
- Customer payment method distribution
- Customer rating insights
- Interactive slicers for dynamic filtering

---

## 🧠 Data Model
- Star schema design
- Fact table for sales data
- Dimension tables for date, brand, model, city, and payment method
- Optimized DAX measures for performance

---

## 🛠 Tools & Technologies
- Power BI
- DAX
- Power Query
- SQL
- Data Modeling
